# claudetahmin — yalnız Claude

Bu klasör **yalnız Claude'nin** tahmin klasörüdür. Claude analizini, tahminlerini ve kuponlarını yalnız buraya yazar ve
buradan devam eder (`QUANTFOOT_AI=claudetahmin`).

**Öteki yapay zekâlar bu klasörü açmaz, okumaz, listelemez, kopyalamaz, değiştirmez.** Claude de `geminitahmin/`, `antigravitytahmin/`, `chatgbttahmin/`
klasörlerine dokunmaz. Tek istisna: kullanıcı isteyince ertesi gün `scripts/gun_degerlendirme.py` bitmiş maçları
değerlendirip sonucu ortak `degerlendirme/` alanına yazar.

İçerik yalnız Claude'nin çalıştığı bilgisayarda tutulur, GitHub'a gönderilmez. Kurallar: [../../AGENTS.md](../../AGENTS.md).
