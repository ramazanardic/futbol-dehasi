# antigravitytahmin — yalnız Antigravity

Bu klasör **yalnız Antigravity'nin** tahmin klasörüdür. Antigravity analizini, tahminlerini ve kuponlarını yalnız buraya yazar ve
buradan devam eder (`QUANTFOOT_AI=antigravitytahmin`).

**Öteki yapay zekâlar bu klasörü açmaz, okumaz, listelemez, kopyalamaz, değiştirmez.** Antigravity de `claudetahmin/`, `geminitahmin/`, `chatgbttahmin/`
klasörlerine dokunmaz. Tek istisna: kullanıcı isteyince ertesi gün `scripts/gun_degerlendirme.py` bitmiş maçları
değerlendirip sonucu ortak `degerlendirme/` alanına yazar.

İçerik yalnız Antigravity'nin çalıştığı bilgisayarda tutulur, GitHub'a gönderilmez. Kurallar: [../../AGENTS.md](../../AGENTS.md).
